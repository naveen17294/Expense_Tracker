## Rules for Ash
1. **Read INDEX.md first** to find which memory file to consult.
2. **Read only the relevant memory file(s)** for the current task.
3. **Update the relevant memory file** after completing work in that domain.
4. **Never dump everything into one file** — keep files focused.
5. **Timestamps** — add `[YYYY-MM-DD]` when logging progress or decisions.
